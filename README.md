# The legend of the princess
Juego de The legend of the princess para la materia programacion de video juegos
Donde implementamos genearion procedural, objetos tomables del entorno, arco y flecha, y jefe final.

# Como instalar y ejecutar:
Clona el repositorio en una carpeta directorio. luego crea un entorno virtual con:
```
python3 -m venv .venv
source .venv/bin/activate       # On Windows: .venv\Scripts\activate
```
Por ultimo instala las dependencias con el comando: (asegurate de estar en el entorno virtual):

```pip install -r requirements.txt```

Finalmente ejecuta: 
```python3 main.py```
